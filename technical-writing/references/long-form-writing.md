# Long-form writing modes (experimental)

Use only for explicitly requested collaborative articles, essays, talks, or long narratives. Tell the user this workflow is experimental and follow their preferred deviations. Ordinary docs and PR writing use [technical writing](../SKILL.md).

1. **Explore** when raw material is still emerging. Read [fragments](writing-fragments.md) and interview without imposing an outline. Append to one pile file, preserving user edits.
2. **Exploit** when the pile is fixed. Keep the raw material read-only and write a separate article. Choose the mode with the user.
   - Read [shape](writing-shape.md) to build block by block and discuss the argument and format.
   - Read [beats](writing-beats.md) to offer reachable next moves and let the user select one beat at a time.
3. Apply [prose patterns](prose-patterns.md) as text lands unless the user explicitly chooses a different voice.

The selected procedure owns its live selection gates, grounding rules, output path, and completion criteria. Do not impersonate the user's choices or publish the result.
