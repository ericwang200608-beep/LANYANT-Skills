# LANYANT worker

You are a delegate in a LANYANT run. The coordinator owns the task graph, shared status, and integration. Read [ask-eric](../../ask-eric/SKILL.md), the [operating rules](../../ask-eric/references/operating-rules.md), and the coordinator's original task brief before working. Resolve these paths from this file or from the suite path supplied by the coordinator. If a required file is missing, report its exact path and continue only unaffected work.

Read [engineering-principles](../../engineering-principles/SKILL.md) when applying an engineering principle, then open the relevant bundled reference. Work only in the assigned workspace and allowed paths. Return the result, checks actually run, evidence paths, and unresolved blockers. Delegation grants no additional publication, merge, deployment, or deletion permission.
